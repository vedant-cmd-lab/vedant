# Sur Detective

A song-intro guessing game. You hear the opening seconds of a track and 
name it before the clock runs out. Bollywood and English, mixed.

Built in two days as a Praxel coursework project.

## Why

The brief was to ship a working app. I wanted something where the 
difficulty tunes itself to how well you actually know music, rather 
than a quiz with a fixed answer key — so the interesting problem was 
the intro clip length. Too long and everyone wins; too short and 
nobody does.

## Built with

- React frontend
- Python backend
- Scaffolded and iterated on Emergent

## Running it locally

Install dependencies in `frontend/` and `backend/`, then start both. 
Environment variables go in `backend/.env` — see the config for what's 
required.
